# ☕ Coffee Point Data Analysis Project

This project simulates and analyzes sales and customer data for a fictional coffee shop — **Coffee Point** — to support data-driven business decisions.

## 📌 Project Features

- **ABC Analysis**: Classifies products based on sales value into A (high value), B (medium), and C (low).
- **FRM Customer Segmentation**: Segments customers using Frequency, Recency, and Monetary value features.
- **Automated Reporting**: Generates visual reports in PDF format using Python and LaTeX via a Bash script.
- **Fully Simulated Data**: All data is synthetically generated using statistical distributions and custom simulation logic.

## 📂 Project Structure

| File | Description |
|------|-------------|
| `data_product.py` | Generates and simulates product-level and customer-level sales data |
| `data_analysis.py` | Performs ABC and FRM analysis, creates visualizations |
| `run.sh` | Bash script to automate running the analysis and generating PDF reports |
| `Coffee Point Analysis in Python.pdf` | Sample output report generated by the system |
